## 模拟专用 SIM1 与真实报文

用户已确认可自生成 SIM1 hex 测试向量并停用 HTTP 运行入口。`SIM1` 为**人为制定**的带类型长度帧，不是上述截图的 A/B/C 报文，不能拿自造 hex 证明真实厂商客户端或 FlexNet wire 兼容。公共管理指南只提供 lmgrd/vendor daemon 职责与端口拓扑，未找到足以可靠重建这些截图中私有 checkout payload 的公开规范。

## 逐字节格式验收的先决条件

1. 经授权的**脱敏双向 PCAP/PCAPNG 或逐报文 hex dump**，包含 TCP 流重组所需信息、同一次测试的服务版本、license/debug log、lmstat 快照与已知操作时间；检查文件中凭证/密钥/用户主机隐私，不能提交生产秘密。
2. 用证据把已知字段、未知字段、可能加密/厂商专有字段分别标注，并为至少两个不同用户/feature 的会话提供请求/响应 golden bytes；仅凭单例偏移不得升格为通用规范。
3. 没有这些证据时，可严格实现**拓扑、独立 PID、端口发现和阶段顺序**，并用明确标记为模拟格式的载荷测试审计融合；**不能宣称严格符合真实报文字节格式**。实际开发前须按批准的范围冻结协议与验收标准。
